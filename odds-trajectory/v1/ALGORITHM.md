# V1 轨迹匹配与评分算法

实现依据为本地 `Pankou/live_dashboard/` 的 `odds_similarity.py`、`odds_point_similarity.py`、`odds_segment_similarity.py`、`odds_point_scoring.py`、`odds_direction_score.py` 与 `direction_score_journal.py`。纯核心见 [code](code/)，参数与源码哈希见[溯源清单](code/SOURCE_MANIFEST.json)。

## 1. 管线和四种数值

处理顺序为：身份及历史候选核验 → 同公司截点前点序 → 严格/近似分类 → 点序/盘段相似分 → 已核验历史结算 → V1 方向原分 → 展示分与色带。

| 数值 | 含义 | 用途 |
| --- | --- | --- |
| 匹配 distance | 关键主客水位差的最大值 | 严格/近似资格 |
| 相似分 S，0–100 | 活跃点位进度中同向升降的比例 | 历史样本排序和 V1 权重 |
| 方向原分 D，0–100 | 带中性收缩的历史上盘正负证据 | 上下盘方向与贡献分 |
| 展示分 E，0–100 | 对 D 的 tanh 显示变换 | 页面色带 |

另外保留历史赢盘率、ROI、RMSE、有效样本量等诊断量，它们不能互相替代。点序评分不改变原严格/近似分类及原组别全样本统计。

## 2. 历史候选与观察截点

公司 1（懂球帝澳彩）和公司 3（Royal）分别比较，仅亚盘 `asia`。设目标开球 K、决策截点 C，则提前量 L=K−C。每个历史候选开球 Kᵢ，使用 Cᵢ=Kᵢ−L；T−10 时 L=600 秒。

历史池排除目标本场和同真实比赛，要求：

- Kᵢ+5400 < C，历史元数据观察时间不晚于 C。
- 常规 90 分钟赛果已核验，主客队来源 ID 均存在。
- 同公司拥有可用赛前轨迹；历史范围可跨联赛、成年/青年/女足/友谊赛，保留类型标签。

历史候选按球队身份和真实比赛去重。原基础 `fixture_key` 使用有来源范围的主客球队 ID（缺 ID 时才为规范名称）及北京时间开球日期；运行中的缓存还核验来源赛事与比赛别名。不能跨来源数字 ID 空间合并，不以模糊名称替代已核验身份。

目标和历史的观察窗口均为“首条有效赛前报价至各自等提前量截点”，不是只截最后 15 分钟，也不统一裁成最近几笔。开球改期及比分别名按[字段说明](../DATA_DICTIONARY.md)的核验口径处理。

## 3. 报价清洗和轨迹特征

使用源 `change_time_local`，保留 `ts ≤ C` 且 `ts < K`、`score` 为空的 `asia` 报价。盘口幅度有限、绝对值≤20、为 0.25 的整数倍；主客水位均有限且在 `(0,3]`。至少 3 条有效赛前记录才生成匹配特征。

本地 line 正值表示主队让球深度、负值表示主队受让。“受”文本决定方向，不单凭来源数值正负号。传入点序参考核心时转换为主队结算让球 `home_handicap = -line`。

同分钟多报价须有一份覆盖全部已入库报价、并与所有已保存来源序列相容的完整顺序证据，才恢复先后。保留 A→B→A。无可靠顺序且发生换盘、首点或末点歧义时整窗不可用；内部同盘多价可保留极值并标记 `tied`，但不能用于可排序的完整点序评分。

连续相同盘口压缩成独立盘段，每段保存起点、末点、主客最低水位和记录数。返回曾出现过的同一盘口仍为新段。若非零 line 同时出现正负两种符号，则让球方翻转，匹配特征不可用。

盘段水位方向定义：

```text
movement(Δ) = +1，若 round(Δ, 2) ≥ 0.03
              −1，若 round(Δ, 2) ≤ −0.03
               0，其余
```

最近变化 `recentDelta` 仅使用末盘口段中最后一个 `ts ≤ C−900` 的真实锚点，比较末报价与该点的主客水位；没有锚点则为 null。T−10 的该锚点对应开球前 25 分钟及以前，不是开球前 15 分钟。

## 4. 严格组与近似组

首先要求目标/历史的 `(首盘, 末盘, giver)` 完全相同。完整压缩 `path` 相同则逐段配对；不同则只配对首段和末段。

对每个对应段，主客起/末水位方向数组必须一致，且计算起/末主客水位差与主客最低水位差。两场 `recentDelta` 必须同时存在或同时缺失；存在时升降方向数组也必须一致，并把变化量差计入最大差 g。

```text
g = max(所有配对起/末主客水位绝对差、配对最低水位绝对差、recentDelta绝对差)
strict = 完整path相同，且 g ≤ 0.05 + 1e−8
approx = 未进入strict，且 g ≤ 0.10 + 1e−8
其余不匹配
```

每组按真实比赛去重，重复记录保留 `(distance, matchId)` 最小者；严格组优先，并从近似组移除已进入严格组的同场。两组互斥，不为凑样本放宽阈值。

分类阈值使用未舍入 g，返回的 `distance=round(g,4)`；重复记录的距离比较使用这个返回值。

## 5. 固定盘口的点序相似分

原始两场各至少 2 笔记录；六位小数规范报价，仅去除相邻完全相同的 `(盘口, 主水, 客水)`。博彩公司、市场、赛前阶段、港式水位、主队视角、窗口 ID 都须相同；固定盘口须完全相同。

去重后 n 个点的位置为 uᵢ=i/(n−1)。单点常值使用 `{0,1}` 断点。两场采用精确 Fraction 进度断点的并集，在点位进度上做分段线性插值，真实时间间隔不参与该分数。

对每个并集区间长度 h，按斜率阈值 ε=1e−9 判断上涨/下降/平。积分区间长度得到：

```text
same       = Σ h × I(两场均变化且同向)
opposite   = Σ h × I(两场均变化且反向)
one_flat   = Σ h × I(仅一场变化)
both_flat  = Σ h × I(两场都平)
active     = same + opposite + one_flat
S_channel  = 100 × same / active，active>0；否则null
```

双方都平的进度不增加分数，也不进入分母；一方平另一方动进入分母。按区间长度积分，不按断点数量投票。

主客通道权重默认各 0.5，仅在正权重且 S 不为 null 的通道间重新归一化方向均分。必须同时保留各通道 `active_coverage`，主客报价联动不代表两份独立证据。

点数按每场完整 `(盘口,主水,客水)` 联合状态序列计，不是主客通道分别去重计数；分段后按每个盘段的联合状态序列计。动态序列去重 2 点仅诊断，3–4 点为低信息诊断，全部动态联合状态序列至少 5 点且有方向证据才可排序；清洗后常值序列不属于动态点数门槛，但原始记录仍须至少 2 笔。没有方向证据时分数为 null。5 点是工程门槛，不是统计显著性保证。

## 6. 幅度诊断与换盘段汇总

点位进度上的水位折线为 A(u)、B(u)，zA=A(u)−A(0)、zB=B(u)−B(0)：

```text
relative_rmse = sqrt(∫₀¹ (zA−zB)² du)
level_rmse    = sqrt(∫₀¹ (A−B)² du)
net_change_gap = |(A(1)−A(0))−(B(1)−B(0))|
区间平方误差积分 = h × (d0²+d0*d1+d1²)/3
```

连续进度加权 Pearson 仅为诊断，不参与方向分。不得用 DTW、按时间加权、每场单独 min-max 或 Z 标准化替代本算法。

换盘前的末点归旧段，新盘首点归新段，不复制端点、不跨盘口插值。同序号且完全相同盘口的段才配对，不跳段或重排。设该段两场清洗点数 aᵢ、bᵢ，全程清洗点数 A、B：

```text
wᵢ = 0.5 × (aᵢ/A + bᵢ/B)
S_total = Σ wᵢ × Sᵢ
```

权重为双方点数占比均值，不是段时长、等权或两场点数直接合并。所有段都有分数才有总分；所有段还须可排序，整体才可排序。缺段、异盘、仅一条原始记录的盘段或无方向段保留未评分权重，不补零也不把权重转给已评分段。至少两条原始记录清洗为一个常值点，与动态段比较可得到有效0分，不能一律视为缺失权重。`partial_direction_score` 只为已覆盖段均分诊断，不能冒充总分。

RMSE 汇总为 `sqrt(Σwᵢ×RMSEᵢ²)`；净变化差等用加权平均。不计算跨换盘 Pearson。可排序样本在各组内按 S 降序、relative_rmse 升序、net_change_gap 升序、matchId 字符串升序排列。

## 7. V1 历史方向聚合

严格组先于近似组，按 matchId 再次去重。只纳入 `rankable=true`、有限 S∈[0,100] 且上盘结算已知的样本。走盘保留五类计数但不进入权重。

| 上盘结算 | z |
| --- | ---: |
| 全赢/半赢 | +1 |
| 全输/半输 | −1 |
| 走盘 | 排除权重 |

```text
wᵢ = (Sᵢ/100)^p；p=0时为1
W = Σwᵢ，Z = Σwᵢzᵢ
D = 50 + 50Z/(α+W)，W>0；否则null
贡献ᵢ = 50wᵢzᵢ/(α+W)
effectiveN = W²/Σwᵢ²
weightedWinRate = (W+Z)/(2W)
```

参数澳彩 p=2、α=50；Royal p=2、α=20。α 为向中性50收缩的固定收缩常数（等效中性权重），权重总和越小越靠近50。半赢与全赢同取 +1，半输与全输同取 −1，未按半场折成0.5。

严格与近似分项各自重算分母，不能把分项分数相加。`(D_strict−50)(D_approx−50)<0` 为 `groupConflict`，当前用于诊断。

D>50 支持上盘，D<50 支持下盘；`abs(D−50)≤1e−8` 视为中性。line≥0 的上盘映射主队，line<0 映射客队；平手盘口按主/客队表述。

原组统计赢盘率为 `(全赢+半赢)/(全赢+半赢+半输+全输)`，每场等权；ROI 保留半赢/半输实际利润且分母包含走盘场次。原组 `smallSample` 使用 n<20；方向展示 N_eff<5 为另一项提示。诊断样本不进入 V1 聚合，不表示原组统计删掉了这些样本。

## 8. 展示分和色带

```text
E = 50 + 50×tanh((D−50)/5)
distance = |float(format(E, '.1f'))−50|
green  : distance < 10
orange : 10 ≤ distance < 25
red    : distance ≥ 25
```

色带描述展示分偏离中性程度，不表示预测准确率或风险等级。原分接近 50 时的微小差异可被 tanh 放大，不能把展示分直接套入 V1 权重。

## 9. 冻结与复现边界

保存观察窗口、报价点序特征哈希、规则与参数版本、公司、截点和来源。复评分优先使用匹配哈希的冻结输入；缺失时只能核验该次候选的完整点序是否仍一致。序列缺失或后来补采改变哈希时，报告不能复现，不能以新行情重造旧评分。

本次包固定 V1 聚合，不启用权重混合或幅度惩罚。现存旧任务可能是在不同参数或不同时间生成；使用当前参数回顾重算必须说明实际计算版本与时间，不称原始已发出的信号。
