# V1 之上的"相似比赛标记加权"研究（Royal T−10）

研究问题：把历史比赛按"与相似比赛结果是否一致"打标记、写入权重，低质量的降权或剔除，高质量的加权，能否提高 V1 的方向胜率和 ROI？

全部计算以 [V1 比对与评分](../v1/) 为准：特征、严格/近似分组、点序/盘段相似分、方向聚合都直接调用 `v1/code` 中未修改的函数，参数为已发布的 Royal `p=2, α=20`。数据为 [2026-10-13 快照](../snapshots/2026-10-13/)。

## 运行

需要 Python 3.10+、numpy、pandas。在仓库根目录依次执行（合计约 3 分钟，4 核）：

```bash
python odds-trajectory/research/build_inputs.py      # 每场 T−10 的 V1 特征、点序、赛果（约 1 分钟）
python odds-trajectory/research/replay_v1.py         # 时间前向 V1 回放 + 全部近邻对日志（约 2 分钟）
python odds-trajectory/research/reliability.py       # 标记加权 / 形态门槛，开发段选参，留出段报告
python odds-trajectory/research/diagnostics.py       # 标记是否带来新信息、价格对照

# 跨公司（澳彩 vs Royal）
python odds-trajectory/research/build_inputs.py --company 1
python odds-trajectory/research/replay_v1.py --company 1      # 澳彩 V1（α=50）
python odds-trajectory/research/cross_company.py [--stage 10]

# 更早阶段
for s in 30 60 120; do
  python odds-trajectory/research/build_inputs.py --stage $s
  python odds-trajectory/research/replay_v1.py --stage $s
done
python odds-trajectory/research/stages.py

# 按赢盘率重新评价全部方案（需先运行以上全部）
python odds-trajectory/research/winrate.py

# 以无模型规则为基础方向，用 V1 轨迹比对确认方向
python odds-trajectory/research/rule_calibration.py
```

两个脚本的参数 `--company`（1=澳彩，3=Royal，默认 3）和 `--stage`（决策截点距开赛的分钟数，默认 10）都可以调整。

中间数据写入 `research/cache/`（不入库），结论数据写入 [`results/`](results/)。

## 方法

**V1 回放（时间前向）**：从 2026-02-01 起，每场比赛按开球时间作为目标。历史池只包含开球 + 5400 秒早于目标截点、已核验 90 分钟赛果、主客队 ID 齐全的比赛，与 [ALGORITHM.md §2](../v1/ALGORITHM.md) 一致。历史池按真实比赛去重，严格组优先。用 numpy 预筛只是为了提速：预筛只剔除 V1 本来就会拒绝的候选（首段或末段水位差超过 0.10、方向键不同），不会多放进任何候选。回放得到的方向原分与直接调用 `score_company` 的结果最大差 7e−15。

**单场标记（你的方案）**：每个可排序的近邻对（目标 t，邻居 j），两场都已结算时，按 `w=(S/100)²` 计入"结果一致"或"结果不一致"。两场比赛都会记录，走盘不计。标记只有在目标结算后（开球 + 5400 秒）才可用，所以任何目标都看不到自己或之后比赛产生的标记。

```
可靠度 r_j = (一致_j + a) / (一致_j + 不一致_j + 2a)       Beta 收缩
新权重 w'_j = w_j × (r_j / (1 − r_j))^γ                    几率比加权
剔除：一致率的 Wilson 95% 上界 < 0.5 的邻居权重置 0
```

**形态门槛**：在同一匹配桶内（首盘、末盘、让球方、首末段方向、近期方向），统计 V1 过去方向判断的命中率（只用截点前已结算的比赛），收缩后高于门槛才下注。

**选参与评估**：开发段为 2026-02-01 至 07-31，所有超参数在开发段按 ROI 选出；留出段为 2026-08-01 至 10-12，用开发段选出的参数原样报告。结算统一用 T−10 那一条 Royal 报价的盘口和水位，ROI 按每注 1 单位计算，半赢/半输按实际利润计。

## 结果

样本：Royal 有 48,961 场可生成 T−10 特征，其中 41,649 场作为回放目标，12,260 场得到 V1 方向；共记录 521,801 个近邻对。

| 方案 | 开发段 N | 开发段 ROI | 留出段 N | 留出段胜率 | 留出段 ROI (±SE) | 一级赛事留出段 ROI |
|---|---:|---:|---:|---:|---:|---:|
| V1 原样 | 6,632 | −2.8% | 5,616 | 52.2% | **−4.5% ±1.2%** | −1.7% ±2.1% |
| V1 + 单场标记（开发段最优 a=20, γ=0.5） | 6,637 | −2.9% | 5,619 | 52.5% | −4.4% ±1.1% | −1.9% ±2.1% |
| V1 + 形态门槛（开发段最优 门槛 0.58） | 373 | −1.5% | 412 | 53.9% | −4.8% ±4.2% | −5.4% ±7.3% |

留出段内，V1 所选方向的市场去水隐含概率平均为 50.6%，实际赢盘率 52.2%，但 Royal 的抽水约 5%，扣掉后 ROI 为负。全部 36 个变体的结果见 [`results/reliability-royal-t10.json`](results/reliability-royal-t10.json)。

### 为什么标记没有提高 ROI

1. **标记确实能预测下一次是否一致**：过往一致率 ≤0.3 的邻居，下一次与目标结果一致的比率是 41.9%；≥0.7 的是 59.0%。
2. **但这部分信息 V1 已经用过了**：过往一致率高（>0.55）的邻居里，86% 本来就和 V1 多数票同向；过往一致率低（<0.45）的邻居里，只有 24% 同向。"一致率高"基本等于"这场的结果和当地多数结果相同"，而 V1 的方向分正是这个多数票。所以重新加权只是把同一张票再算一次，留出段 ROI 没有改善。
3. **V1 相似分 S 和分组的区分度很弱**：全部近邻对的结果一致率是 50.8%。S 在 85 以上时一致率是 52–54%，但这样的近邻对只有 1,405 个；严格组和近似组的一致率相同（50.7% 对 50.8%）。
4. **控制 T−10 价格后，V1 强度没有增量信息**：在开发段的 V1 选择上拟合 logit(赢盘) ~ logit(市场去水概率) + |D−50| + log(1+有效样本)，|D−50| 的系数为 **−0.58**。V1 所选方向"胜率比市场隐含高约 2 个百分点"，可以由市场本身的校准偏差解释（市场项斜率 1.18 > 1）。按模型期望值筛选，留出段同样为负。

详细数值见 [`results/diagnostics-royal-t10.json`](results/diagnostics-royal-t10.json)。

## 跨公司：澳彩 vs Royal（T−10，按 Royal 价格下注）

[`cross_company.py`](cross_company.py) 读取 Royal 每个目标在截点时的澳彩报价，清洗规则与 V1 相同，但只要有 1 条报价就可以使用。两家公司换算到同一刻度"等效让球数" `s = 盘口 + K·(去水主胜盘概率 − 0.5)`，K = 4.63 球/单位概率，由开发段 Royal 自身的升降盘估计。

- **覆盖**：47,781 场 Royal 目标中，18,153 场在截点时有澳彩报价，其中 74% 两家盘口相同。澳彩的 V1 方向因报价稀疏，只覆盖 599 场，无法作为特征使用。
- **抽水**：Royal 中位数 4.9%，澳彩 6.9%。
- **跟随澳彩全部亏损，而且比随机更差**：两家等效让球差超过 0.10 球时，按 Royal 价格买澳彩看好的一方，留出段胜率 44.8%（市场隐含 48.2%），ROI −8.1% ±2.4%。也就是说，**Royal 是更领先的一方**，两家不一致时多数是澳彩还没跟上。
- **反向（跟 Royal、反澳彩）也没有可用的优势**：差值超过 0.10 时，开发段 ROI −2.1% ±1.7%，留出段 −0.2% ±2.2%，在开发段的任何门槛下都为负。澳彩报价越旧，反向的胜率越高；但澳彩近 30 分钟内刚变过的话，反向反而更差。
- **把澳彩作为公允价**（不需要拟合参数）：EV 大于 0、2%、4%、6% 时，开发段和留出段全部为负。
- **逻辑回归**：在市场价格之外加入差值、两家各自 T−60 以来和初盘以来的变化、澳彩报价的新旧程度，留出段对数损失只改善 0.00005。T−60 和 T−120 阶段加入后反而变差（−0.0001、−0.00014）。EV 门槛下的 ROI 在开发段和留出段之间正负翻转，属于噪声。

结论：在 Royal 的价格上，**澳彩没有提供可以下注的增量信息**；两家的差异主要来自澳彩更新慢。结果见 `results/cross-company-T{10,60,120}.json`。

## 更早阶段：T−120 / T−60 / T−30 / T−10

[`stages.py`](stages.py) 对每个阶段运行完全相同的 V1 时间前向回放，并按该阶段的 Royal 报价结算。

| 阶段 | 留出段 N | 胜率 / 市场隐含 | 留出段 ROI | 一级赛事留出段 ROI | 开发段 ROI | 收盘线价值（概率点） |
|---|---:|---|---:|---:|---:|---:|
| T−120 | 5,835 | 53.5% / 50.6% | −2.5% ±1.1% | −0.9% ±1.9% | −3.3% ±1.0% | −0.10 |
| T−60 | 5,830 | 52.0% / 50.6% | −4.7% ±1.1% | −1.4% ±1.9% | −3.2% ±1.0% | −0.06 |
| T−30 | 5,795 | 51.9% / 50.6% | −4.8% ±1.1% | −5.0% ±2.0% | −3.6% ±1.0% | −0.04 |
| T−10 | 5,616 | 52.2% / 50.6% | −4.5% ±1.2% | −1.7% ±2.1% | −2.8% ±1.1% | — |

- **没有一个阶段的 ROI 为正**。T−120 在留出段最好，但开发段是 −3.3%，两段不一致，不能认定为优势。
- **收盘线价值全部为负**：V1 在早期选的方向，到 T−10 时 Royal 的价格平均反而往相反方向移动 0.04 到 0.17 个概率点。V1 没有提前捕捉到后来的市场变化。
- **V1 强度的系数正负不定**：控制价格后，|D−50| 的系数在 T−120 为 +1.14、T−60 为 −0.17、T−30 为 +0.94、T−10 为 −0.50，没有稳定的方向。
- **最后两小时价格的信息量变化很小**：在同盘口的 27,682 场比赛中，用各阶段的去水概率预测赛果，对数损失 T−120 为 0.69117，T−10 为 0.69025，只改善 0.0009。Royal 的价格在 T−120 时已经基本定型，后面的变化很少，所以提早决策也没有可以利用的"未定价"空间。

结果见 [`results/stages-royal.json`](results/stages-royal.json)。

## 按赢盘率评价（全赢、赢半都算赢，走盘剔除）

评价口径与模拟投注页一致：`(全赢+赢半)/(全赢+赢半+输半+全输)`。

**注意：直接比较赢盘率会被盘口类型干扰。** 赢半算作赢，所以四分之一盘会天然抬高某一方的赢盘率。T−10 留出段的情况：

| 不用任何模型的规则 | 开发段赢盘率 | 留出段赢盘率 |
|---|---:|---:|
| 永远买上盘 | 48.6% | 48.7% |
| 永远买低水一方 | 52.5% | 53.6% |
| .25 盘买受让方（平局赢半）、.75 盘买让球方（赢一球赢半），其余买低水 | **54.8%** | **55.1%** |

为了排除这个影响，[`winrate.py`](winrate.py) 在开发段拟合一个**只看价格和盘口类型**的基准：按整球、.25、.5、.75 四类盘口分别给截距和斜率，用去水上盘概率预测上盘赢盘率。**提升 = 实际赢盘率 − 基准预期**。上表中的规则，提升都在 ±0.6 个百分点以内，说明基准已经吸收了盘口类型的影响。所有方案都按开发段的提升选参，再原样在留出段检验。

| 方案 | 开发段提升 | 留出段 赢盘率 / 基准 / 提升 | 一级赛事留出段提升 |
|---|---:|---|---:|
| V1（T−10） | +0.9 ±0.6 | 52.2% / 52.1% / **+0.1 ±0.7** | +1.0 ±1.2 |
| V1 + 单场标记（开发段最优） | +0.8 ±0.6 | 52.5% / 52.3% / +0.2 ±0.7 | +0.8 ±1.2 |
| V1 + 形态门槛（开发段最优） | +1.8 ±2.6 | 53.9% / 54.4% / −0.6 ±2.4 | −1.6 ±4.1 |
| 跟随澳彩（等效让球差 >0.10） | −0.6 ±1.0 | 44.8% / 47.1% / −2.4 ±1.4 | −2.4 ±2.3 |
| 反向澳彩（等效让球差 >0.10） | +0.6 ±1.0 | 55.2% / 52.8% / **+2.4 ±1.4** | +2.4 ±2.3 |
| V1（T−120） | +0.4 ±0.6 | 53.4% / 52.6% / **+0.9 ±0.7** | +1.4 ±1.1 |
| V1（T−60） | +0.6 ±0.6 | 52.0% / 52.3% / −0.3 ±0.7 | +1.2 ±1.1 |
| V1（T−30） | +0.4 ±0.6 | 51.9% / 52.1% / −0.2 ±0.7 | −1.0 ±1.2 |

单位为百分点，± 为一个标准误。

- **V1 本身**：开发段和留出段的提升都为正，合计约 +0.5 个百分点（约 1 个标准误），但不显著。
- **单场标记、形态门槛**：都没有带来稳定的赢盘率提升。
- **两段都为正、值得继续观察的只有两项**：
  - 反向澳彩：开发段 +0.6，留出段 +2.4，合计约 +1.3 ±0.8 个百分点。
  - V1 在 T−120：开发段 +0.4，留出段 +0.9。
  
  两者都还没有达到 2 个标准误，需要更多数据确认。
- **模拟投注页的 57.6%**：半球和整球盘（不可能出现赢半/输半）是 52.4%（99/189），四分之一盘是 62.8%（120/191）。四分之一盘本身会抬高赢盘率，建议投注页也按盘口类型分别统计，或者同样和基准比较。

结果见 [`results/winrate-royal.json`](results/winrate-royal.json)。

## 以无模型规则为基础，用 V1 轨迹比对确认方向

[`rule_calibration.py`](rule_calibration.py) 先用 T−10 的 Royal 报价按规则定方向：.25 盘买受让方，.75 盘买让球方，其余买低水一方。规则本身的赢盘率是开发段 54.8%、留出段 55.1%。然后用 V1 的方向做三种处理：**确认**（V1 同向才下注）、**跳过**（V1 反向且足够强时不下注）、**改向**（V1 反向且足够强时改买 V1 的一方）。

**V1 不能用来改向。** V1 与规则反向时，规则一方仍然赢 52.7%（开发段）和 54.4%（留出段）；改买 V1 一方只有 47.2% 和 45.6%。无论 V1 强度多大，改向都会拉低赢盘率。

**V1 适合用作确认过滤**，赢盘率如下（提升 = 相对价格加盘口类型基准，单位百分点）：

| 规则 + 过滤条件 | 开发段 赢盘率（提升） | 留出段 赢盘率（提升） | 一级赛事留出段 | 留出段 N |
|---|---|---|---|---:|
| 只用规则 | 54.8% (−0.1) | 55.1% (+0.2) | 54.9% | 15,182 |
| T−10 V1 同向 | 55.8% (+0.5) | 55.7% (+0.2) | 56.3% | 3,445 |
| T−120 V1 同向 | 55.9% (+0.6) | 57.0% (+1.6) | 56.9% | 3,474 |
| T−10 和 T−120 都同向 | 56.3% (+0.4) | 57.3% (+1.5) | 59.2% | 1,765 |
| T−120 同向且 T−10 不反向 ※ | **56.5% (+1.0)** | **57.7% (+2.2)** | 57.8% | 2,775 |

※ 这一组合是在看过留出段之后才加入的，只能作为前瞻检验的候选规则，不能把 57.7% 当作已验证的结果。

- 同一批比赛中，V1 同向和反向的赢盘率差距：T−120 为开发段 +2.5、留出段 +2.7 个百分点，每段约 2 个标准误；T−10 为 +3.1 和 +1.3。V1 的方向确实带有关于规则可靠性的信息。
- 部分提升来自"同向"组的盘口和水位更有利（基准从 54.9% 升到约 55.5%），其余是 V1 自身的信息。
- ROI 仍未转正：最好的组合留出段为 −0.4%，一级赛事为 +0.5%。

结果见 [`results/rule-calibration.json`](results/rule-calibration.json)。

## 结论与下一步

- 在这份数据上，"按相似比赛结果一致性给历史比赛打标记"能识别出邻居的一致性，但这些信息与 V1 自身的多数票高度重复，**没有提高 ROI**。不建议用它删除库里的比赛。
- 瓶颈不在历史库的质量，而在 **Royal 的价格已经包含了水位路径的信息**。
- **跨公司（澳彩）**：Royal 领先，澳彩滞后。按 Royal 价格下注，跟随或反向都没有稳定优势。
- **更早阶段**：T−120 到 T−10 都没有正 ROI，V1 的收盘线价值为负，Royal 的价格在两小时前就已基本定型。
- 后续值得尝试的方向，都是 Royal 价格之外的信息或更好的价格：
  1. **Bet365**：它是快照里第三家公司，赛前报价同样稀疏，但可能比澳彩更领先，可以用同一个脚本检验（需要先过滤滚球记录）。
  2. **更好的执行价格**：反过来利用"澳彩滞后"，在澳彩买 Royal 已经移动过去的一方。前提是澳彩确实可以下注；需要用澳彩的水位重新结算。
  3. **非赔率信息**：首发、伤停、赛程密度等，Royal 价格可能还没完全反映。
  4. 继续把"该阶段的去水概率"作为必须超过的基准。

## 局限

- 这是回顾重算：快照里的报价是后来采集的历史，不能证明当时已能拿到。历史池没有检查"元数据观察时间早于截点"，因为快照里的采集时间都晚于 2026-08-31。
- V1 已发布参数的训练截止是 2026-09-28，与开发段重叠，因此开发段的 V1 结果可能略偏乐观；留出段中 09-28 之后只有约 2 周。
- 下注和结算都按 Royal 价格。澳彩的 V1 已经接入（`--company 1`，α=50），但因为报价稀疏，只用于覆盖率统计。
- 半赢/半输按 V1 口径记 ±1 参与标记；ROI 按实际利润计。
